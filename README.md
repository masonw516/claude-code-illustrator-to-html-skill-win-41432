## About Illustrator-to-HTML Skill

Illustrator-to-HTML Skill is an educational package for using Claude Code during the transition from Adobe Illustrator web layouts to working HTML and CSS. It brings design exports, SVG and PNG assets, specifications, and browser renderings into a structured implementation and review process.

The materials are intended for learners, instructors, and developers who want a repeatable way to translate visual references into responsive interfaces. Alongside implementation guidance, the package emphasizes HTML organization, maintainability, accessibility, and visual comparison across PC, tablet, and smartphone layouts.

## Usage

A typical workflow can follow these steps:

1. Review the Illustrator reference files, exported assets, and specifications.
2. Identify the target layouts for PC, tablet, and smartphone screens.
3. Ask Claude Code to help organize the source material and implementation tasks.
4. Build the page structure with HTML and style it with CSS.
5. Use SVG and PNG assets where appropriate.
6. Render the page in a browser and compare it with the reference image.
7. Refine layout differences, structure, maintainability, and accessibility.
8. Repeat the browser validation cycle until the implementation matches the intended design.

Example prompts can be adapted to the current exercise:

```text
Review the Illustrator exports and propose an accessible HTML structure for this page.

Compare the reference image with the current browser rendering and list the largest layout differences.

Inspect the HTML and CSS for maintainability issues across desktop, tablet, and smartphone layouts.
```

## Configuration

The package uses the project materials and Claude Code skill files contained in the repository rather than a required global configuration file. Project-specific guidance should be kept with the relevant exercise, while reusable personal skills can be maintained separately from the learner and instructor materials.

Before beginning an exercise, confirm:

- Which reference assets are part of the assignment.
- Which viewport layouts need to be supported.
- Whether the task is intended for learner or instructor use.
- Where generated HTML, CSS, SVG, and image files should be placed.
- Which browser-rendering comparisons are required.

## FAQ

### Who is this package for?

It is designed for learners, instructors, and developers working from Adobe Illustrator web designs toward browser-based HTML and CSS implementations.

### Does it include both student and teaching content?

Yes. The package provides separate learner and instructor materials.

### How are responsive layouts handled?

The workflow considers PC, tablet, and smartphone layouts and encourages comparison between the reference artwork and browser renderings.

### Where should I begin?

Check the relevant exported assets and specifications first, then compare the reference and browser output by viewport. Address structural and responsive differences one step at a time.
